## 1. شنوّة هذا المشروع؟

**Genio OS** = منصّة AI **محلية** (Local-First) متاع **HiTech Lab TN**، تجمع في بلاصة وحدة:

- شات مع **6 وكلاء** (agents) عندهم شخصيات ودوار مختلفة
- **سرب وكلاء** (Swarm) يكتب الكود مباشرة في الـ workspace
- **Web IDE** حي + **طرفية ويب** (Web Terminal)
- **RAG** (قاعدة معرفة محلية)
- **ذاكرة** (playbooks + سجل تجارب JSONL) + **self-heal** (إصلاح ذاتي)
- لوحة **إدارة النماذج** + خريطة **3D Voxel**

المحرّك يخدّم على **Ollama** (محلي، على `pop-os:11434`)، والـ backend **FastAPI** + **Uvicorn**.

**التقنيات:** Python 3.14.4 • FastAPI • Uvicorn • httpx • psutil • HTML/CSS/JS خام (بلا framework) • Docker/Ollama خارجيًا.
